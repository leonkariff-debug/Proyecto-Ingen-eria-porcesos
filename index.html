Datos provenientes del PDF

Alimentación de 100 kmol/h, mezcla equimolar a 25 °C; precalentamiento a 40.32 °C; columna de 24 etapas, alimentación en la 11, reflujo 10, D=55 y B=45 kmol/h; fondos calientes 110.4 °C, enfriados a 83 °C.

Balance y redondeos

El documento de referencia indica xD(benceno)=0.91 y xB(tolueno)=0.999. Con F=100, z=0.5, D=55 y B=45 esos valores redondeados no satisfacen simultáneamente el balance de benceno: para xB(benceno)=0.001 resulta xD≈0.90827. La web calcula la fracción de fondos por balance y advierte sobre entradas inviables.

Modelos simplificados

Esta web no ejecuta DWSIM ni reproduce el equilibrio de etapas o la recirculación rigurosa. REC-009 presenta una demostración numérica de convergencia. El intercambiador emplea una correlación de referencia ajustada al caso base; los deberes térmicos emplean escalamiento proporcional didáctico. Para predicciones termodinámicas rigurosas se debe recalcular en DWSIM.

Publicación y pruebas

Aplicación estática sin dependencias externas, ejecutable con un servidor local o GitHub Pages. Consulta el README para configuración, pruebas, supuestos, créditos y publicación. Los valores del caso base se pueden restablecer en cualquier momento.
